    How to use

    1. Optionally choose a base school to load all student residences zoned to that assignment, or leave it blank to start from the map only.
    2. Choose a selection tool (lasso or paintbrush) and mode (select or erase). A single click on a hex (without dragging) always toggles that hex on or off, no matter which mode is on. If a hex is not selectable, it is because no students live there.
    3. Click Confirm selection to load or refresh the summaries. Change hexes on the map anytime; summaries update only when you confirm. Use Clear selection to remove all selected hexes.

    Optional: choose a base school to load all zoned student residences. You can add or remove hexes using the tools below.
